= Multicluster Management with Red Hat OpenShift Platform Plus (DO480)

[.big]#*Course description*#

*Enhance container management capabilities with automation, governance, and security across clusters.*

Multicluster Management with https://www.redhat.com/en/technologies/cloud-computing/openshift/platform-plus[Red Hat OpenShift Platform Plus] teaches the skills required to maintain a diverse portfolio of applications, running across a fleet of OpenShift clusters. Applications follow placement rules determined by capacity and criticality; cluster configurations comply with governance and security policies; all automated according to https://www.redhat.com/en/topics/devops[DevOps] principles.

This course is based on Red Hat OpenShift Container Platform 4.10 and Red Hat Advanced Cluster Management 2.4.

*Note:* This course is five days. Durations may vary based on the delivery. For full course details, scheduling, and pricing, select your location then “get started” on the right hand menu.

[.big]#*Course content summary*#

* Deploy https://www.redhat.com/en/technologies/management/advanced-cluster-management[Red Hat Advanced Cluster Management for Kubernetes (RHACM)] in a hub cluster
* Add a managed cluster to RHACM (configure a cluster to be managed by RHACM)
* Define and apply cluster configuration policies
* Detect and correct non-conformance to cluster configuration policies
* Visualize and compare cluster settings between different clusters
* Define and apply application placement policies
* Identify and compare application resources from multiple clusters
* Deploy https://www.redhat.com/en/technologies/cloud-computing/quay[Red Hat Quay] in the hub cluster
* Deploy Red Hat Advanced Cluster Security for Kubernetes (RHACS) in the hub cluster
* Integrate Red Hat Quay and RHACS with RHACM.

[.big]#*Audience for this course*#

* System Administrators, Developers, Site Reliability Engineers, and IT Architects interested in managing and automating the management of a fleet of OpenShift clusters, possibly in different data centers and cloud providers.
